# Finance Database Management System 💰

A **SQL-based Finance Database Management System** designed to manage and analyze banking-related data. This project demonstrates practical use of **MySQL database concepts**, including database creation, table relationships, constraints, data insertion, joins, aggregate functions, subqueries, CTEs, and window functions.

### 📌 Features

* Customer and account management
* Branch and employee management
* Loan and payment tracking
* Transaction management
* Debit/Credit card records
* Account balance history
* Overdraft policy management
* Employee audit logs
* Account-transaction relationships
* Financial data analysis using SQL queries

### 🗄️ Database Tables

The database includes tables for:

* `customer`
* `branch`
* `account`
* `loan`
* `employee`
* `transact`
* `card`
* `history`
* `overdraft_policy`
* `payment`
* `audit_log`
* `account_transaction`

### 🧠 SQL Concepts Used

* `CREATE DATABASE` and `CREATE TABLE`
* Primary and Foreign Keys
* `INSERT` and `ALTER TABLE`
* `JOIN`
* `GROUP BY` and `HAVING`
* Aggregate functions such as `SUM()`, `COUNT()`, and `AVG()`
* Subqueries
* Common Table Expressions (CTEs)
* Window functions
* `DENSE_RANK()`
* Running totals using `SUM() OVER()`
* Data filtering and sorting

### 🎯 Purpose

This project was created to practice **database design and SQL query development** using a real-world finance/banking scenario. It demonstrates how relational databases can be structured and queried to manage financial information efficiently.
